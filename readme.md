# Práctica 1: Introducción a Markdown

Este repositorio contiene la resolución del ejercicio práctico para aprender la sintaxis básica de **Markdown**.

## 📋 Descripción del ejercicio

El objetivo de este proyecto es crear un archivo escrito en Markdown (`miprimermd.md`) que incluya diversos elementos de formato estructurados según las especificaciones del ejercicio.

### Requisitos del archivo `miprimermd.md`:

1. **Título principal**
2. **Subtítulo**
3. **Párrafo** con texto en **negrita**, *cursiva* y `código en línea`.
4. **Bloque de código**
5. **Lista ordenada**
6. **Lista desordenada**
7. **Enlace a una URL externa**
8. **Enlace a otro archivo Markdown** dentro del repositorio.
9. **Imagen**
10. **Tabla**

---

## 🛠️ Instrucciones para clonar el repositorio

Para descargar este proyecto en tu entorno local, ejecuta el siguiente comando en la terminal:

```bash
git clone https://github.com/albertomartii/ejercicio_markdown1.git
cd ejercicio_markdown1
```
